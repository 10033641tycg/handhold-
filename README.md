# 個別訪談 現場速查卡

兒少性剝削個案個別訪談時，現場卡住可以快速查的提示卡，給實務工作者使用。

**線上使用：** https://10033641tycg.github.io/handhold-/

## 怎麼用

找到眼前的情境，每張卡依「別這樣／試這樣／一句帶走」呈現；部分卡片會一步步帶你分辨孩子的狀態，幫你找方向，不替你下判定。

情境分類：認知與自我、情緒與激動、界線與試探、揭露與保密的壓力、辨識狀態並調整、家庭與多方、現場與你自己。

## 使用原則

- 「一句帶走」都是草稿，請換成你自己的話，依孩子的年齡與狀態調整。
- 本卡為現場提示，不取代訪談前的準備、督導討論與相關工作手冊。
- 依據：《兒童及少年性剝削防制新法工作手冊》及實務框架。

## 資料治理

單檔、不連網、不留存任何資料，所有操作只在本機。提供淺色與深色兩種主題，跟隨裝置設定。
